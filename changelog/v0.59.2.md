# v0.59.2

Changes since 0.59.1.

## Added
- `make setup`, `config/.env.example` and matching ignore entries for a ready development environment (CR-001).
- `make build` builds the package and runs a wheel smoke program importing every dependency (CR-001).
- Offline smoke tests covering each core and integration dependency (CR-001).
- Agent guidance in `AGENTS.md` and `CLAUDE.md`, and a fixed Claude hook that no longer activates the venv (CR-001).
- Documentation structure: `docs/PRD.md`, `docs/ARCHITECTURE.md` and `docs/changes/` change requests, linked from the README (CR-001).

## Changed
- Starlette middleware now records `http.route` for plain Starlette applications as well as FastAPI.

## Maintenance
- Toolchain updated to uv 0.13.5 and Python 3.15 (3.14 still supported); dependencies refreshed in `uv.lock`.
