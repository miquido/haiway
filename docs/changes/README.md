# Change requests

Changes are recorded as change requests in this directory, one file each, named
`CR-NNN-<short-name>.md` (for example `CR-001-dev-environment.md`). Numbers are sequential.

## Structure

A change request contains:

- Problem: the current state and what is wrong or missing.
- Decisions: numbered `D1 — …` entries with the choices made and why.
- Requirements: sections headed `R1 — <title>` (anchors such as `#r1--<title>`), each with a goal,
  scope and acceptance criteria.
- Open questions: anything undecided, marked "Open".
