# Specifications

Specifications of haiway changes and designs, one directory per kind. Each directory's `README.md`
states its rules and indexes its documents.

| Directory                   | Kind                            | Prefix |
| --------------------------- | ------------------------------- | ------ |
| [design/](design/README.md) | Technical design specifications | `TDS`  |

This catalog lives outside `docs/`: MkDocs builds only `docs/` with `--strict`, so nothing under
`docs/` links here.
